deterministic program for the
[make.fun](https://make.fun/competitions/u-0xb3e689-one-star-review-of-something-essential-c7234629)
bounty "One-Star Review of Something Essential".

## The review

> One star. Gravity has held me down my entire life and never once offered to help me carry the groceries upstairs.

## How it works

`main.ts` (Node 22+) writes that single line to `/output/entry.txt`. No
network, no randomness, no input files — the same bytes every run.

```sh
node main.ts
```
